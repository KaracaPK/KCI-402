กำหนดกฎ Student, Guest หรือ Admin ให้สมาชิกตามห้อง กฎจะปรับสมาชิกปัจจุบันและสมาชิกที่เพิ่มหรือย้ายห้องในภายหลัง โดยกฎ Student/Guest จะไม่ลดบัญชีที่เป็น Admin อยู่แล้ว

การเลือก Admin จะให้สิทธิ์จัดการระบบแก่สมาชิกทุกคนในห้องนั้น และระบบจะแจ้งให้ยืนยันก่อนบันทึก
